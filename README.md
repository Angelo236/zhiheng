# 知衡 · 个人多 Agent 管理平台

知衡是一款面向学习、生活和工作的个人桌面应用。通过任务清单、日历和确认收件箱管理日常安排，并为多个 Agent 配置职责、模型、技能和自主权。

项目当前为 `0.1.0`，包含本地持久化、演示数据和模型调用接口。无需模型密钥即可体验任务、日程、复习和审批；运行 Agent 前，需要在设置中配置模型连接。

## 使用说明

[查看或下载《知衡使用说明手册》（PDF）](docs/zhiheng-user-manual.pdf)

图文手册共 15 页，包含 13 张界面截图，介绍首次启动、任务与日程、收件箱、学习复习、Agent 配置、模型连接和常见问题。适用于 `0.1.0` 版本。

## 功能

- **今天**：查看当日任务与时间轴，安排未排期任务，处理时间冲突。
- **收件箱**：确认、退回或暂缓 Agent 提出的改动。
- **任务与日程**：管理学习、生活、工作任务，查看日程和每周时间预算。
- **学习**：按主题查看复习卡，通过“记住了 / 模糊 / 忘记”调整复习间隔。
- **Agent**：预置统筹、学习、日程、生活、回顾和资料六位成员，管理职责、技能、自主权与安静时段。
- **活动**：查看运行步骤、提案和执行结果，保留重跑前的记录。
- **资料与设置**：维护笔记，配置模型、预算和睡眠时段，恢复演示数据。

模型提出的改动通过规则层处理，再根据自主权写入数据或送入收件箱。时间预算、睡眠时段与冲突检查参与这一过程。

## 技术栈

| 部分 | 技术 |
| --- | --- |
| 桌面端 | Electron、electron-builder |
| 前端 | React、TypeScript、Vite、React Router |
| 后端 | Fastify、TypeScript、Zod |
| 数据 | SQLite，使用 Node.js 内置 `node:sqlite` |
| 项目组织 | npm workspaces，共享类型位于 `packages/shared` |
| 模型接口 | 兼容 Chat Completions 的 HTTP 接口 |

## 本地运行

开发环境使用 **Node.js 24** 和 npm；macOS 用于桌面应用运行与 `.app` / `.dmg` 打包。

```bash
git clone https://github.com/Angelo236/zhiheng.git
cd zhiheng
npm ci
npm run dev
```

浏览器访问 <http://127.0.0.1:5173>。开发脚本同时启动前端和后端，后端默认监听 `127.0.0.1:8787`。

需要启动桌面窗口时，在另一个终端运行：

```bash
npm run desktop
```

首次启动会初始化演示数据；设置中的“恢复演示数据”会重置当前数据。部分示例日程固定在 2026 年 10 月，供产品演示使用。

## 模型配置

在设置中填写 Base URL、模型名和 API Key，再测试连接。Base URL 应是接口前缀，例如包含服务所需的 `/v1`；程序会在其后追加 `/chat/completions`。

没有配置密钥时，Agent 运行会显示原因。实际模型效果与可用性取决于所配置的服务，本仓库不附带任何服务凭据。

## 检查与打包

```bash
# 前后端类型检查
npm run typecheck

# 构建前端与后端
npm run build

# 在 macOS 上构建桌面应用与 DMG
npm run pack
```

桌面产物位于 `apps/desktop/release/`。当前打包配置未启用应用签名，安装包不包含在源码仓库中。

## 目录

| 路径 | 内容 |
| --- | --- |
| `apps/web` | 前端页面与样式 |
| `apps/desktop` | Electron 主进程、预加载脚本与打包配置 |
| `services/api` | 数据库、业务规则、模型调用和 HTTP API |
| `packages/shared` | 前后端共享类型与工具函数 |
| `scripts` | 开发启动脚本 |

开发模式的数据默认写入 `services/api/data/`；桌面模式写入 Electron 的用户数据目录。依赖、构建产物、本地数据库、密钥文件和环境配置已加入 `.gitignore`。

当前版本面向单用户本机使用，尚未提供账号、云同步和外部日历集成。API 使用本地开发鉴权约定，不作为公网服务部署方案。
